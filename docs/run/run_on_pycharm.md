# Как запустить MVP в PyCharm (очень-очень простая инструкция)

Привет! 👋

Ниже — пошаговый гайд, как запустить проект **с нуля**, даже если ты раньше этого не делал.
Я специально написал максимально просто.

---

## 0) Что тебе понадобится

1. **Компьютер** с Windows / macOS / Linux.
2. **Интернет** (чтобы скачать нужные программы).
3. **PyCharm** (лучше Community или Professional).
4. **Python 3.11** (или 3.10+).
5. Сам проект (папка с файлами, где есть `manage.py`).

---

## 1) Устанавливаем Python

Если Python уже есть — всё равно проверь версию.

### Windows
1. Открой сайт: https://www.python.org/downloads/
2. Скачай Python 3.11.
3. При установке **обязательно поставь галочку**: `Add Python to PATH`.
4. Нажми Install.

### macOS
1. Открой сайт: https://www.python.org/downloads/
2. Скачай Python 3.11 для macOS и установи.

### Linux
Обычно Python уже есть. Если нет — установи через пакетный менеджер.

---

## 2) Ставим PyCharm

1. Открой: https://www.jetbrains.com/pycharm/download/
2. Скачай и установи PyCharm.
3. Запусти PyCharm.

---

## 3) Открываем проект в PyCharm

1. Нажми **Open**.
2. Выбери папку проекта (там, где лежит файл `manage.py`).
3. Подожди, пока проект загрузится.

---

## 4) Создаём виртуальное окружение (очень важно)

Виртуальное окружение — это отдельная «коробка» с библиотеками для проекта.

1. В PyCharm открой:
   - **File → Settings** (на macOS: **PyCharm → Settings**)
2. Перейди в:
   - **Project: <имя проекта> → Python Interpreter**
3. Нажми шестерёнку ⚙️ → **Add Interpreter**.
4. Выбери **Virtualenv Environment**.
5. Нажми **OK**.

Подожди, пока интерпретатор создастся.

---

## 5) Устанавливаем зависимости проекта

1. В PyCharm открой нижнюю вкладку **Terminal**.
2. Убедись, что ты в папке проекта (где `manage.py`).
3. Выполни команду:

```bash
pip install -r requirements/base.txt
```

Дождись конца установки.

---

## 6) Применяем миграции базы данных

Это создаст локальную базу SQLite со всеми таблицами.

В терминале выполни:

```bash
python manage.py migrate
```

Если всё хорошо — увидишь много строк с `OK`.

---

## 7) (Опционально) Создаём администратора

Чтобы войти в админку:

```bash
python manage.py createsuperuser
```

Придумай email и пароль.

---

## 8) Запускаем сервер

В терминале:

```bash
python manage.py runserver
```

Если всё ок, появится что-то вроде:

`Starting development server at http://127.0.0.1:8000/`

Теперь открой браузер и зайди на:

- http://127.0.0.1:8000/

---

## 9) Как быстро проверить, что MVP работает

### Проверка 1: Главная страница
Открой `http://127.0.0.1:8000/` — страница должна открыться без ошибки.

### Проверка 2: Регистрация / вход
- Зарегистрируй пользователя.
- Войди под ним.

### Проверка 3: Сценарии и диалог
- Открой список игр.
- Запусти сценарий.
- Отправь хотя бы одно сообщение.
- Заверши диалог.
- Должен открыться экран результатов.

### Проверка 4: PDF
- На экране результатов нажми экспорт PDF.
- Должен скачаться PDF-файл.

### Проверка 5: Админка
- Открой: `http://127.0.0.1:8000/admin/`
- Войди суперпользователем.

---

## 10) Как запустить автотесты

В терминале проекта:

```bash
python manage.py test
```

Если хочешь запустить только важные наборы:

```bash
python manage.py test apps.dialogs.tests apps.analysis.tests apps.exports.tests apps.core.tests
```

---

## 11) Самые частые ошибки и что делать

### Ошибка: `ModuleNotFoundError: No module named 'django'`
Значит, зависимости не установились.

Сделай:

```bash
pip install -r requirements/base.txt
```

### Ошибка: «порт занят»
Кто-то уже использует 8000.

Запусти так:

```bash
python manage.py runserver 8001
```

И открой: `http://127.0.0.1:8001/`

### Ошибка с миграциями
Попробуй ещё раз:

```bash
python manage.py migrate
```

---

## 12) Мини-шпаргалка (коротко)

```bash
pip install -r requirements/base.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
python manage.py test
```

---

Если всё сделал по шагам — MVP должен запускаться и работать локально ✅
